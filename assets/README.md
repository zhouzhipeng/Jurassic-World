# 游戏资源

本目录保存已导出的游戏资源，以及描述它们的制作清单和许可证。注册入口为根目录 `resources.settings`；修改路径前必须检查所有引用。

- `models/`：GLB 模型、动画、LOD 和模型制作清单。
- `environment/`：天空、海面、贴图、HDR 制作输入及许可证。
- `audio/`：原创合成音乐、音效与音频清单。
- `ui/`：触屏和背包 SVG。
- 根目录现有 PNG、SVG、WAV 和字体沿用已注册路径。

可编辑 Blender 文件在 `sources/`，TSL 源码在 `materials/`，制作脚本在 `tools/`。来源记录见 [资源来源清单](../docs/ASSET_SOURCES.md)。
