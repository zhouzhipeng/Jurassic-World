# 开发产物

- `verification/legacy/`：从原开发文档目录迁入的历史验收记录。
- `verification/touch/`：触屏改造的报告、说明与截图。
- `verification/inventory/`：背包网格验收报告，对应截图在 `previews/`。
- `verification/survival/`：生存系统报告与截图。
- `verification/coastal/`：海岸环境报告与截图。
- `previews/`：独立预览截图。
- `local/`：本地临时产物，Git 忽略，按需创建。

这些文件不是游戏运行资源。历史通过结果只适用于报告记录的版本，不能代替当前版本验证。新的验收报告按 [目录约定](../docs/PROJECT_STRUCTURE.md) 保存。
