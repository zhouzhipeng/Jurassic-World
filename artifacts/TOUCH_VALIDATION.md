# 手机触屏改造验证

源代码版本：`448d2ab` — Separate building controls on short touch screens。

默认界面改为手机触屏。左摇杆移动、外圈奔跑，右侧空白滑动转视角；互动按钮根据附近资源、水源、篝火、工坊、坐骑和门切换。点一下完成一轮采集，移动可以取消。背包采用直接点击的食物与配方卡，建造采用部件、旋转、放置及楼层按钮。建造时「部件」替换背包入口，避免与楼层按钮重叠。

原有天气、昼夜、温度、生存、伙伴、生产、任务及存档继续使用原生 IfDo 事件。本次没有增加 JavaScript 游戏事件。触控使用原生触点编号；检索了官方 reviewed 扩展 SpriteMultitouchJoystick 1.9.2，选择较小的场景适配以复用现有 3D 移动。
