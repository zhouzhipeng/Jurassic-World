# Coastal vegetation and dinosaur elevation

- Issue: `issues/issue-20260923-065025-062.md`
- Source revision: `0fefac8` — Align vegetation and wildlife with coastal terrain
- Scene: `Game`
- Date: 2026-09-23

## Cause and change

The coast mesh generated by `tools/build_walkable_coast.py` attenuates mountain
height within 24 m of the shoreline. `MountainInitialize.events`,
`MountainFoliage.events`, and `MountainActors.events` still set plant and
wildlife elevations from the unattenuated mountain profile. At sample spawn
positions, this raised a raptor by 1,138 game units and a berry bush by 1,160
units above the coast ground.

`tools/mountain_profile.py` now defines the coast floor in both Python and native
event expression form. `tools/sync_coast_elevation.py` applies it to the 16
object elevation actions. The coast mesh builder uses the same Python floor.
No GLB was replaced.

The runtime check compared elevation against the mesh generator's shared floor
formula. It did not perform a new mesh raycast at every affected instance.
