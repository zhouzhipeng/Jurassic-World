# 侏罗纪世界 — GDevelop 交互概念 Demo

用 GDevelop 打开 `project.gdevelop`，运行 `Game` 场景。

## 当前实现

- 实时 3D 海岛、木屋营地、副栉龙和背包角色；第三人称移动、跟随镜头、营地障碍和活动边界。
- F3 切换到清爽卡通 3D 效果图参考模式：溪边驯养、海边营地。
- 真正的原生 GDevelop 界面对象：生存状态、任务提示、快捷栏、背包、制作、暂停、设置、标题菜单。
- 喂食消耗浆果，提高信任；信任封顶 100。
- 采集浆果/纤维、木材/石头；采集消耗体力，饮水休息恢复体力和水分。
- 石斧与长矛配方，校验并扣除材料、增加背包数量；材料不足不会制作。
- 营地加固状态与材料消耗。
- 本地存档、读档；包含资源、驯养、营地建设、当前站点（不保存角色精确坐标）。
- 菜单和背包打开时暂停生存消耗。

## 操作

| 输入 | 操作 |
|---|---|
| WASD | 按镜头方向移动 |
| 鼠标右键拖动 | 环绕角色旋转、调整俯仰 |
| 滚轮 | 拉近或拉远镜头 |
| Home | 重置镜头 |
| F3 | 切换实时 3D / 效果图参考 |
| E | 溪边喂食 / 营地加固 |
| R | 采集浆果和纤维 |
| G | 采集木材和石头 |
| F | 饮水、休息 |
| Q | 前往恐龙或营地站点 |
| Tab | 打开或关闭背包 |
| Esc | 暂停或返回 |
| 鼠标 | 点击按钮、选取配方、查看物品说明 |

操作在按键释放时执行，按住不会重复获得资源。存档需在暂停菜单手动点击 Save Game；重启后通过 Load Game 恢复。

## 与概念图的差别 / 尚未实现

这是 **实时 3D 玩法原型 + 效果图参考模式**。界面的布局、配色和功能参照概念图实现；三维场景使用自行制作的简化模型，尚未达到 1:1 的模型、材质和构图还原。

实时模式支持 WASD 平面移动和靠近喂食；模型暂无行走或恐龙动画。没有骑乘、战斗、寻路、联机、自由放置建筑。采集与饮水是演示按钮操作，不检测资源节点距离。加固营地目前改变进度和物资，未切换建筑模型。Photo Mode 只隐藏 HUD，不提供相机移动。健康、角色等级和世界日期为演示设定。背包不支持拖拽、分类搜索或装备替换；快捷栏支持点击与数字键 1–8：采集、长矛制作、喂食、饮水、绷带状态、营火休息、营地加固、背包。尚无战斗武器切换。

要进一步逼近效果图，需要精修角色、恐龙与植被模型，补充骨骼动画，并继续调整地形、光照和材质。

## 文件

- `project.gdevelop`：项目入口，1600×900。
- `scenes/Game/scene.settings`：界面布局、图层与初始变量。
- `scenes/Game/functions/sceneUpdate.events`：原生事件逻辑，未使用私有运行时或浏览器脚本。
- `scenes/Game/objects/`：独立可编辑的 Sprite / Text 对象。
- `assets/`：场景底图、独立物品图集、角色预览、SVG 面板和本地字体。
- `assets/models/`：三个 GLB 模型和可编辑 Blender 源文件；共 11,910 三角面。
- `verification.json`：通过 GDevelop 预览输入执行的检查记录。

背景及物品素材由内置 ImageGen 生成；UI 面板为代码生成 SVG，文字、状态条、交互和存储由 GDevelop 原生对象与事件驱动。物品图集使用 Sprite sourceRect 引用，不把整张背包截图用作功能界面。

项目采用小型专用原生事件实现，无需引入第三方扩展。
