# 侏罗纪世界 — GDevelop 交互概念 Demo

用 GDevelop 打开 `project.gdevelop`，运行 `Game` 场景。

## 当前实现

- 实时 3D 海岛、木屋营地、副栉龙和背包角色；第三人称移动、跟随镜头、营地障碍和活动边界。
- F3 切换到清爽卡通 3D 效果图参考模式：溪边驯养、海边营地。
- 真正的原生 GDevelop 界面对象：生存状态、任务提示、快捷栏、背包、制作、暂停、设置、标题菜单。
- 喂食消耗浆果，提高信任；信任封顶 100。
- 信任达到 100 后，靠近恐龙按 X 或点击骑乘按钮上下坐骑；WASD 控制坐骑，角色以坐姿跟随鞍座。恐龙有待机呼吸、颈部与尾部轻摆，以及交替迈步的行走骨骼动画。
- 角色与恐龙通过随朝向旋转的胶囊范围分离；下坐骑检查两侧落脚点。坐骑受到营地与海岛边界限制，菜单暂停运动与动画。骑乘时需先下坐骑才能采集或快速旅行。坐骑位置和骑乘状态不进入存档，读档恢复步行。
- 18 个独立资源点：红果灌木、蕨类、小树和矿石。靠近 2.6 米内互动：灌木、蕨类和矿石按住 E 0.8 秒采集；小树须按 1 装备斧子，按住 E 或在场景中央按住左键砍伐。小树需要三次命中，每次消耗 1 体力、间隔 0.5 秒，砍完获得 4 木材并计入任务。
- 斧子有独立手持 3D 模型和挥动、树木剩余命中次数与敲击音；其他采集有进度百分比、资源晃动、音效、获得材料提示及背包数量更新；松开 E 或离开范围取消进度。采完隐藏，30 秒后恢复。菜单暂停恢复计时。
- 植物高度：灌木约 1.7 米、蕨类约 1.2 米、小树约 4 米；低草保留为不可采集的环境装饰。
- 石斧与长矛配方，校验并扣除材料、增加背包数量；材料不足不会制作。
- 模块建造：B 开启，1 地基 / 2 柱子 / 3 墙 / 4 门框 / 5 楼板 / 6 木门 / 7 楼梯 / 8 篝火。WASD 调整前方预览、R 旋转 90°、Enter 放置、PgUp/PgDn 选择施工楼层、B 退出。支持 128 件构件、3 个施工楼层；绿色可建，红色显示受阻原因。
- 地基按 300 单位网格连续铺设；墙和门框吸附边缘，柱子吸附角点，楼板连接墙/柱顶部，门安装在门框中。E 开关附近木门；楼梯可步行上楼，顶部楼板可作为下一层地板。未搭支撑的构件不能悬空放置。附近无威胁时，篝火每秒恢复 2 生命、5 体力，楼板遮蔽区域恢复 8 体力。
- 建造模式选择对应构件类型和楼层，指向目标，Delete 拆除并返还一半材料（向下取整）；有子构件依附时需先拆子构件。位置、类型、楼层、朝向、门状态和支撑关系通过 BuildingsV2 手动保存 / 读取。兼容旧 BuildingsV1 中的整栋木屋、栅栏和篝火，旧木屋/栅栏可直接指向拆除。地基占用区域的资源暂停重生，读档后也不会穿入地板。
- 本地存档、读档；包含资源、驯养、营地建设、当前站点（不保存角色精确坐标）。
- 菜单和背包打开时暂停生存消耗。
- 5 种恐龙：可骑乘副栉龙；在南部活动的三角龙、剑龙；在北部警戒与追击的迅猛龙、霸王龙。新恐龙都有待机、行走动画，食肉恐龙另有张口撕咬动画。
- 真实生命值、攻击前摇和伤害间隔。步行按空格反击，有长矛时每次 35 伤害，否则使用石斧近战 12 伤害；每次消耗 3 体力、间隔 0.65 秒。击退食肉恐龙获得生肉和兽皮。
- 营地周围 3.3 米是庇护区，每秒恢复 4 生命。倒下后按 Enter 重生，保留工具、扣除 3 浆果和 1 生肉，获得 5 秒伤害保护。骑乘时受到的伤害减半。
- 原创 48 秒探索 BGM《岛屿初曦》，80 BPM；另有同步循环的危险节奏层，追击时自动渐入。新增 18 个交互与生物音效，沿用采集和斧击声音。首次鼠标/键盘互动启动音乐；M 或声音按钮静音。

## 任务与核心玩法

按 **J** 或点击右上角「生存手册」查看当前目标、操作步骤、进度和奖励。顶部按镜头方向显示目标方位与距离，优先指向尚未采完的资源。

| 阶段 | 完成条件 | 奖励 |
|---|---|---|
| 第一份食物 | 实际采集 3 浆果 | 浆果 +3 |
| 就地取材 | 实际采集 4 木材、3 石头、5 纤维 | 木材 +6、石头 +2、纤维 +4 |
| 亲手制作 | 在背包制作 1 根长矛 | 体力 +30，最高 100 |
| 第一位伙伴 | 恐龙信任达到 100 | 兽皮 +2 |
| 安全的营地 | 1 地基、3 墙/门框、1 顶部楼板 | 绳索 +2、解锁补给委托 |
| 野外补给委托 | 本轮新采集上述四种材料 | 绳索 +2、体力 +25、饥饿与水分 +15 |

目标达成后在手册点击领取，主线推进到下一步；补给委托每次领取后重新计数。初始库存不计入采集任务，提前采集或制作的真实操作会记录。领取奖励自动保存当前资源与任务进度，普通未领取的任务进度也可通过暂停菜单手动保存。重启后用 Load Game 恢复；旧版存档保留原有资源，任务从第一步开始。手册打开时暂停移动、采集和生存消耗。

任务用本项目的小型原生事件状态机实现，没有引入第三方任务扩展。

## 操作

| 输入 | 操作 |
|---|---|
| J | 打开或关闭任务手册 |
| WASD | 按镜头方向移动 |
| X | 信任 100 后靠近骑乘；再次按下安全下坐骑 |
| 鼠标右键拖动 | 环绕角色旋转、调整俯仰 |
| 滚轮 | 拉近或拉远镜头 |
| Home | 重置镜头 |
| F3 | 切换实时 3D / 效果图参考 |
| 1 | 装备斧子（背包须有斧子） |
| 2 | 打开长矛制作配方 |
| 空格 | 步行反击附近食肉恐龙，优先使用背包中的长矛 |
| M | 全局静音 / 恢复声音 |
| B / 1～8 / R / Enter / Delete | 开关建造 / 选择构件 / 旋转 / 放置 / 拆除 |
| PageUp / PageDown | 建造时切换施工楼层（1～3） |
| Enter | 倒下后在营地重生 |
| E / 场景中央左键 | 装备斧子后靠近小树，按住连续砍伐 |
| E | 其他资源按住采集；附近无资源时松开喂食 / 打开营地建造 |
| R | 显示靠近资源按住 E 的提示，不直接获得材料 |
| G | 显示资源采集提示，不直接获得材料 |
| F | 饮水、休息 |
| Q | 前往恐龙或营地站点 |

采集按住 E 完成，已采资源进入恢复时间；其余快捷操作在按键释放时执行。存档需在暂停菜单手动点击 Save Game；重启后通过 Load Game 恢复。

## 与概念图的差别 / 尚未实现

这是 **实时 3D 玩法原型 + 效果图参考模式**。界面的布局、配色和功能参照概念图实现；三维场景使用自行制作的简化模型，尚未达到 1:1 的模型、材质和构图还原。

当前为单机小岛原型。野生恐龙使用有限状态巡游与直接追击，未实现复杂地形寻路、捕猎其他动物、野生恐龙驯服或骑乘攻击。角色与恐龙使用简化碰撞范围，尚未实现全场景物理碰撞。玩家具有待机、行走、奔跑、采集、挥斧、突刺、受击和倒地骨骼动画；按住左 Shift 奔跑并消耗体力，武器跟随右手骨骼。饮水仍为演示按钮操作；资源恢复计时、野生动物状态、生命值和声音偏好不进入存档，重启场景后重置。建造已改为木制模块拼接，采用固定正方形网格和保守的单父级承重关系；尚无石制/金属升级、斜屋顶、耐久、恐龙拆墙、自由角度或网络多人同步。建筑采用简化碰撞；现有岛屿装饰模型尚无完整碰撞。Photo Mode 隐藏 HUD。角色等级和世界日期为演示设定。背包不支持拖拽、分类搜索或自由装备替换。

要进一步逼近效果图，需要精修角色、恐龙与植被模型，补充骨骼动画，并继续调整地形、光照和材质。

## 文件

- `project.gdevelop`：项目入口，1600×900。
- `scenes/Game/scene.settings`：界面布局、图层与初始变量。
- `scenes/Game/functions/sceneUpdate.events`：原生事件逻辑，未使用私有运行时或浏览器脚本。
- `scenes/Game/objects/`：独立可编辑的 Sprite / Text 对象。
- `assets/`：场景底图、独立物品图集、角色预览、SVG 面板和本地字体。
- `assets/models/`：地形、角色、可骑乘副栉龙、四种野生恐龙和工具的 GLB 与 Blender 源文件；新野生恐龙合计 8,100 三角面。
- `assets/audio/`：原创循环音乐、危险节奏层、交互音效和音频清单。
- `AUDIO-DESIGN.md`：配器、声音触发点与混音设计。
- `tools/build_wildlife.py` / `tools/compose_audio.py`：可重复制作模型与原创音频的源脚本。
- `verification-survival.json`：本次音频、追击、战斗、重生和回归验证记录。
- `verification.json`：通过 GDevelop 预览输入执行的检查记录。

背景及物品素材由内置 ImageGen 生成；UI 面板为代码生成 SVG，文字、状态条、交互和存储由 GDevelop 原生对象与事件驱动。物品图集使用 Sprite sourceRect 引用，不把整张背包截图用作功能界面。

项目采用小型专用原生事件实现，无需引入第三方扩展。

建造验证：`verification-construction.json` 与 `construction-preview.png`。检索官方扩展仓库后未找到适配当前原生 3D 建筑和资源流程的建造系统；二维 SnapToGrid 也不适用，因此采用小范围原生事件实现。存档测试将 `SaveStorage` 临时设为独立测试槽，正常游戏默认仍为 `JurassicWorldDemo`。

## 三倍地图扩展

可步行范围从 3000 × 2950 扩为 5200 × 5100（面积约 2.997 倍）：X 为 −2600～2600，Y 为 −2800～2300。营地、玩家和已有建筑坐标保持原位。陆地、海岸树木、草地和探索小径重新生成；可采集资源从 18 处增加到 54 处（15 浆果、15 蕨类、12 树木、12 石矿）。食草恐龙分布在南侧草地，食肉恐龙分布在北侧外围。步行、骑乘、下坐骑、野生恐龙和建造范围同步扩大，骑乘与建造边界保留体积安全距离。

地形生成源：`tools/build_expanded_island.py`，模型：`assets/models/island.glb`；原 `island-source.blend` 保留，新编辑源为 `island-expanded-source.blend`。

## HUD 与角色组件结构

- `scenes/Game/external-layout/`：7 个独立布局，共 249 个 UI 实例，分别为 GameHUD、GameInventory、GamePause、GameSettings、GameTitle、GamePhoto、GameQuests。场景中不再放置这些 UI 实例。
- `scenes/Game/external-events/`：HUDBootstrap 在场景首帧创建布局一次；26 份按职责命名的 HUD 事件负责菜单输入、快捷栏、背包制作和保存反馈、采集提示、任务、生命/受伤/死亡提示、建造选择与显示。调用顺序保留原事件顺序，避免输入重复消费和拾取范围变化。`ui-module-map.json` 记录模块清单。
- `scenes/Game/objects/`：保留 GDevelop 原生 External Layouts 必须引用的 UI 对象定义，统一放在编辑器的 UI / External Layouts 分组。外部布局拥有 UI 摆放，外部事件拥有 UI 执行逻辑。
- `extensions/JurassicActors/prefabs/`：Survivor、Parasaur、Triceratops、Stegosaur、Raptor、Tyrannosaur 六个真实 3D Prefab。场景中的 Player3D、Dinosaur3D 等名称和实例 UUID 保持不变，但类型已替换为这些 Prefab。
- Survivor 拥有 Body、HeldAxe、CombatSpear，内部处理动画播放及 GripR 骨骼装备绑定；Parasaur 拥有 Body 和 MountedRider，骑手随父级移动/转向。恐龙 Prefab 各自拥有模型、动画生命周期及独立实例状态。场景只提交 AnimationState、AnimationPlaying 和装备/骑手可见状态，跨角色交互、世界碰撞和玩家输入由场景编排。
- 野生恐龙 AI 按实例循环处理，复制同种 Prefab 时不会共用移动坐标；出生位置在首帧放置完成后初始化。Prefab 为新对象定义补齐默认实例状态，场景对象声明用于编辑器校验与参数定制。
- 原场景 HeldAxe、CombatSpear、MountedRider 定义和实例已移除。旧的一次性 author_* / setup_construction 生成器已加版本检查，避免覆盖新的组件结构；后续请直接编辑上述组件文件。

## 木制模块建造

构件成本（木 / 石 / 纤维）：地基 6/2/3、柱子 3/0/1、墙与门框 4/0/2、楼板 5/0/3、门 3/0/1、楼梯 6/0/3、篝火 3/3/0。第一层地板高 20，每层高 300。第 1 层选择楼板是在 320 高度封顶；切换第 2 层可在该楼板上继续搭墙。楼梯朝其本地前方上升，R 调整；上方需留洞口，把楼板接在楼梯尽头。

世界建造逻辑位于 `scenes/Game/external-events/ModularConstruction.events`，HUD 仍由 HUDBuildSelection、HUDBuildPresentation、HUDBuildStatus 及 GameHUD external layout 独立维护。模型与编辑源为 `assets/models/modular-*`，由 Blender 后台脚本 `tools/build_modular_assets.py` 制作；不修改玩家/恐龙 Prefab。

复用检索：官方扩展仓库提交 `6e0bba82e5123cd95ea06107056d4015ae0d78e3`；SnapToGrid 0.0.5 是二维取整网格，未提供三维连接点、支撑、门或分层碰撞。沿用现有原生建造事件扩展本项目规则更直接，因此未引入扩展或 JavaScript 运行事件。

运行验证见 `verification-modular-construction.json`；测试仅使用独立存档槽，不覆盖玩家的 JurassicWorldDemo。

## 外部事件片段（格式 6）

每个片段只有 `scenes/Game/external-events/<名称>.events` 一个 IfDo 文件，不需要 settings、functions 子目录或登记清单。当前 28 个片段共 28 个文件。`link external "名称"` 在原位置展开正文，继承父条件、对象筛选和局部变量；执行顺序由 Link 所在位置决定，与文件名排序无关。场景自身的生命周期函数仍使用 settings/events 文件对。

2026-09-20 一次性重构保留了全部事件正文和 28 处引用（含 4 处子事件引用），删除 56 个包装文件及 56 个目录。编写指南与 tools 中相关生成脚本已同步；请使用支持格式 6 的新引擎打开。校验记录见 [external-events-migration.md](external-events-migration.md)。
