# 海岛生存 · 手机触屏操作

默认使用手机 Web 触屏界面，随横竖屏和窗口尺寸调整。采集、食物、水源、营地、伙伴和金属升级组成 12 步任务，点左上当前目标查看详情与领取奖励。

| 操作 | 触屏方式 |
| --- | --- |
| 移动 | 拖动左下摇杆，推至外圈自动奔跑 |
| 转视角 | 滑动右侧空白处，可以同时移动或攻击 |
| 互动 | 右下按钮自动切换采集、喂食、骑乘、饮水、烤肉、工坊或开关门 |
| 攻击 | 点按或按住「攻击」，按原有冷却连续攻击 |
| 补给 | 缺水时优先饮水，否则优先吃烤肉，再吃浆果 |
| 背包 | 20 格图标布局，竖屏四列、横屏五列；点选图标查看数量和说明，再点食用或装备 |
| 制作 | 背包详情区保留长矛、石斧快捷配方；材料不足时按钮禁用 |
| 建造 | 选部件，再点「放置」「旋转」「层 + / −」；「管理」可拆除附近构件 |
| 导航和存档 | 点「菜单」选择目的地、保存或读取 |
| 重生 | 倒下后点「在营地重生」 |

采集点一次即可完成一轮，砍树会自动选斧头。移动、打开菜单或离开目标会取消采集。篝火缺少燃料时会自动添加一份木材，再烤一份生肉。打开菜单会暂停世界并清除持续手势，返回后需要重新触碰。

存档保存在当前浏览器与当前设备。电脑也能用鼠标点击触屏按钮，以下快捷键保留为可选操作。

背包图标显示材料、食物、水袋和工具的实时数量，空格不能触发操作。生肉与烤肉分开显示；水袋角标显示剩余饮水次数。点选物品不会消耗物品，滑出格子后松手取消操作；已经吃饱、食物用完或材料不足时，对应按钮禁用。横屏将物品详情放在右侧，竖屏放在网格下方。

## 远征规则与可选键盘操作

1. 找红果灌木和蕨类，按住 E 采集。按 1 装备斧头后砍树；Tab 制作长矛，空格攻击。
2. Q 依次切换任务、清泉、营地工作台、三角龙和金属矿区导航。顶部显示相对镜头的方向与距离。副栉龙驯服后按 X 骑乘赶路。
3. 清泉旁 F 饮水。营地工作台旁 I 制作水袋，消耗 2 兽皮、4 纤维；到清泉 F 装满，野外可饮用三次，每次恢复 40 水分。
4. 营地篝火或自己建造的篝火旁，V 添加 1 木材，获得 45 秒燃料，最多存储 180 秒。C 消耗 1 生肉开始烹饪，8 秒后得到烤肉。熄火后保留烹饪进度，添柴继续。
5. 3 吃浆果，恢复 8 饥饿值；5 吃烤肉，恢复 30 饥饿值和 8 生命。吃饱后不会继续消耗食物。
6. 走近三角龙按 T，每次消耗 3 浆果、增加 20 信任，间隔 4 秒。五次喂食后驯服；周围有捕食者时不能喂食。H 切换跟随与留守，伙伴在 7.2 米内时，浆果和纤维产量翻倍。
7. 前往北部六处金属矿脉，按住 E 1.8 秒开采。基础工具每次得到 2 矿石，矿脉 180 秒后恢复。这里有迅猛龙和霸王龙，带好武器与补给。
8. 营地工作台旁 Z 修复熔炉，消耗 12 石头、8 木材。之后 Z 每次消耗 2 矿石和 2 木材，10 秒熔炼出 1 金属锭。
9. 修好的熔炉旁 U 制作金属工具，消耗 3 金属锭、4 木材、2 兽皮。每次开矿产量变为 4，木材变为 6，石头变为 5；长矛伤害升至 55。升级永久生效。
10. 完成一次狩猎后，解锁循环远征委托：采矿、烹饪、狩猎，领取金属锭与绳索奖励。

## 天气、时间和生存

游戏一天默认 12 分钟，开始于第一天 08:00。白天、黄昏与夜晚的光照和雾色平滑变化，晴、多云、雨、雷暴和雾会轮换。

饥饿值与水分分别消耗，任何一项耗尽都会伤害生命。雨中会逐渐淋湿，湿冷的夜晚可能使体温跌破 35°C 并持续造成伤害。屋顶能挡雨并帮助干燥，燃烧的篝火能迅速烘干身体、恢复体温。体力不足时休息，屋顶下恢复更快。

建造仍使用 B、数字键、R 和 Enter；建造模式的 8 选择篝火。F6、F7 保留为天气切换和时间快进的调试键。

## 存档与暂停

新增存档保存食物、水袋、矿石、工具等级、体温、湿度、任务、熔炉生产进度、各篝火的燃料和烹饪任务、矿脉冷却、三角龙信任/命令/位置、副栉龙位置以及玩家位置。骑乘时保存，载入后会在坐骑旁下马。菜单打开期间，生存消耗、环境伤害、生产和伙伴移动全部暂停。旧存档会使用新增系统的默认初始值。

## 实现与验证

玩法使用原生 IfDo 事件；不包含 JavaScript 游戏事件。模型由 `tools/build_survival_assets.py` 通过 Blender 生成，`sources/models/survival-*-source.blend` 保留源文件，每个 GLB 都经过重新导入检查。

已检查官方扩展缓存中的 ExtraInventory 与 Health：前者已废弃，后者会与现有角色生命、无敌时间和伤害流程重复。因此新增功能沿用本项目已有的库存变量和原生生命流程。

新增测试为 SurvivalSupplies、CompanionGathering、MetalProgression、SurvivalExposure、SurvivalPersistence，覆盖真实按键、材料消耗、队列暂停/恢复、任务领奖、伙伴收益、装备伤害和存档恢复。

触屏层同样使用原生 IfDo，复用现有移动、生产、战斗与存档。已检索 reviewed 中的 SpriteMultitouchJoystick 1.9.2；其多套行为映射对本项目自定义 3D 移动过于宽泛，本次使用引擎原生触点标识作场景适配。TouchControls、TouchSurvival、TouchMenus、TouchResponsive 覆盖多点触控、自动采集、补给、建造、存档和自适应分辨率。横竖屏还通过实际调整预览窗口检查。

网格背包使用 `TouchInventoryLayout.events`、`TouchInventoryInput.events` 和 `GameTouchInventory.settings`，复用现有物品图集和库存，不另建库存系统。`TouchInventoryGrid` 验证点选、滑出取消、食物选择、空格、数量、装备及材料扣除；`TouchResponsive` 另检查网格与按钮边界。2026-09-21 全部 19 项测试、232 条断言通过，记录在 `artifacts/verification/inventory/inventory-grid-verification.json`，横竖屏预览在 `artifacts/previews/pack-grid-landscape.png`、`artifacts/previews/pack-grid-portrait.png`。
